# MetaGuildX

MetaGuildX is being bootstrapped from the provided blueprint without changing the business logic. The repository is split into:

- `apps/web`: React + Vite frontend for the landing page and dashboard
- `contracts`: Hardhat-based Solidity workspace for OPBNB deployment targets
- `docs`: frozen product and system specifications derived from the blueprint

## Getting Started

1. Install dependencies from the repository root.
2. Start the frontend workspace.
3. Compile the contracts workspace.

## Workspace Scripts

- `npm run dev:web`
- `npm run build:web`
- `npm run dev:contracts`
- `npm run build:contracts`
