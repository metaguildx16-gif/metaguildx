# Frontend Architecture

## Goal

Provide two main user experiences:

1. Public landing page
2. Wallet-gated dashboard

## Landing Page Sections

- Hero with tagline and connect wallet CTA
- About MetaGuildX
- System overview
- Package ladder
- Income streams
- Roadmap preview
- Contact footer

## Dashboard Sections

- User panel
- Tree visualization
- Income cards
- Referral tools
- Level summary table
- Rebirth tree panel
- Internal wallet actions
- Staking overview panel

## Frontend State Direction

- Wallet connection state
- Network state
- User profile state
- Package state
- Income summary state
- Tree node state
- Staking state

## Data Strategy

The first scaffold uses static blueprint-derived data. Contract reads and transaction wiring will be introduced after ABI integration.
